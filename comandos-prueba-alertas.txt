COMANDOS DE PRUEBA DE ALERTAS RESPEL
Fecha de referencia: 2026-05-02

IMPORTANTE
- Estos comandos son para PowerShell.
- Levanta la app con `npm run dev`.
- La app y la API quedan normalmente en `http://localhost:5173`.
- No uses `^` para continuar lineas en PowerShell. Eso es de `cmd`.

COMO FUNCIONA
- La alerta de categoria real usa los 6 meses completos anteriores al mes del registro.
- Si registras una entrada en mayo de 2026, la categoria real evalua de 2025-11-01 a 2026-04-30.
- La alerta proyectada usa el mes actual mas los 5 anteriores.
- Si registras una entrada en mayo de 2026, la proyectada evalua de 2025-12-01 a 2026-05-31.
- El promedio se calcula solo con los meses que si tienen entradas.

UMBRALES
- Pequeno Generador: >= 10 y < 100 kg/mes
- Mediano Generador: >= 100 y < 1000 kg/mes
- Gran Generador: >= 1000 kg/mes

1. LEVANTAR APP

npm run dev

2. RESETEAR BASE LOCAL AL ESTADO INICIAL

npx wrangler d1 execute respel --local --file=./scripts/reset-prod-db.sql

3. CONSULTAS RAPIDAS

Invoke-RestMethod -Method Get -Uri "http://localhost:5173/api/generators/default"
Invoke-RestMethod -Method Get -Uri "http://localhost:5173/api/alerts/category"
Invoke-RestMethod -Method Get -Uri "http://localhost:5173/api/alerts/projected-category"

4. PRUEBA: ALERTA PROYECTADA A MEDIANO

npx wrangler d1 execute respel --local --file=./scripts/reset-prod-db.sql

$body = @{
  generator_id = 1
  name = "Bateria usada"
  hazard_code = "TO"
  weight_kg = 120
  recorded_at = "2026-05-02T10:00:00Z"
} | ConvertTo-Json

Invoke-RestMethod -Method Post `
  -Uri "http://localhost:5173/api/waste-entries" `
  -ContentType "application/json" `
  -Body $body

Invoke-RestMethod -Method Get -Uri "http://localhost:5173/api/alerts/projected-category"
Invoke-RestMethod -Method Get -Uri "http://localhost:5173/api/alerts/category"
